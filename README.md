# Lindol

**Quakes near me.** A free web tool that lists recent earthquakes within a set distance of any Philippine city, with magnitude, depth and time in PHT, a short drop-cover-hold card, and a link to PHIVOLCS for official bulletins.

**For:** households, schools, and newcomers to the Philippines.

Status: being built. See the build brief in the issues.

## Data and attribution
Earthquake data comes from the [USGS Earthquake Hazards Program GeoJSON feeds](https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php) (free, no API key; US government public domain). This tool is not an official source: for official Philippine earthquake bulletins and tsunami advisories, follow [PHIVOLCS](https://www.phivolcs.dost.gov.ph/). It links to PHIVOLCS and does not republish PHIVOLCS data.
